# Project Brief: Smart Travel Concierge

## Overview
A conversational AI travel concierge that plans personalized trips, remembers traveler preferences, searches flight/hotel options, calculates trip budgets, and generates destination visuals.

## Target Audience
Travelers looking for personalized, end-to-end trip planning and itinerary management.

## Core Capabilities & Tool Mapping
1. **Memory & Sessions**: Remembers user travel preferences (budget level, dietary restrictions, favorite hotel chains, seat preferences).
2. **Tools**: Looks up flights, hotels, and local weather forecasts.
3. **Catalog & A2UI**: Renders structured itinerary cards, hotel listings, and flight comparison tables.
4. **Visuals**: Generates destination landmark previews using Gemini image generation.
5. **Code Sandbox**: Computes daily travel budget breakdowns and currency conversions.

## Primary Workflows
- **Trip Planning**: Collect travel dates and destination, retrieve stored preferences, and generate a day-by-day itinerary card.
- **Budget Calculation**: Run budget math in Python sandbox and output total cost breakdowns.
- **Visual Exploration**: Generate high-quality destination previews on demand.
